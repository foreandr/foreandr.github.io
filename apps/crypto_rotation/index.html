📡 Fetch the data first

This app needs historical CoinMarketCap data. Run the Python script once to generate crypto_history.js, then reload this page.

pip install requests tqdm
python fetch_data.py

The script pulls monthly snapshots of the top 200 coins from 2010 to today (~a few minutes). Data is saved locally — no API key required.
